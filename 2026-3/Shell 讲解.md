# Shell 讲解

## 变量

1. 定义变量

    ```sh
    var="value"
    ```

    > **注意**
    >
    > - 变量名与等号之间不能有空格
    > - 变量名只能包含字母、数字和下划线（大小写敏感）
    > - 变量名不能以数字开头
    > - 变量名避免使用 Shell 关键字（例如 if、then、else、fi、for、while 等）
    > - 使用全大写字母与下划线命名常量（例如 `PI=3.14`）
    > - 变量名中避免使用特殊字符与空格

2. 使用变量

    ```sh
    echo $var
    echo ${var}
    ```

    变量名外的花括号是可选的，加花括号能够明确变量名边界。

    ---

    通过 `readonly` 命令可以将变量定义为只读变量

    ```sh
    var="value"
    readonly var
    var="other value"   # 报错，只读变量不可更改
    ```

    ---

    通过 `unset` 命令可以删除变量

    ```sh
    var="value"
    echo $var   # output 'value'
    unset var
    echo $var   # output empty
    ```

3. 变量类型

    在 Shell 中，变量通常被视为字符串，双引号字符串中可以使用变量，单引号字符串不行。

    ---

    **特殊变量**：

    - `$0`：脚本名称
    - `$1` `$2` `$n`：脚本参数
    - `$#`：脚本参数数量
    - `$?`：上一个命令的退出状态
    - `$*`：以一个单字符串显示所有向脚本传递的参数。如 `"$*"` 会以 `"$1 $2 … $n"` 的形式输出所有参数。
    - `$$`：脚本进程 ID 号
    - `$!`：后台运行的最后一个进程的 ID 号
    - `$@`：与 `$*` 相同，但是使用时加引号，并在引号中返回每个参数。如 `"$@"` 会以 `"$1" "$2" … "$n"` 的形式输出所有参数。
    - `$-`：显示 Shell 使用的当前选项，与 `set` 命令功能相同。

## 输入/输出重定向

大多数 UNIX 系统命令从终端接受输入并将所产生的输出发送回​​到终端。一个命令通常从标准输入的地方读取输入，默认情况下，这恰好是你的终端。同样，一个命令通常将其输出写入到标准输出，默认情况下，这也是你的终端。

**重定向命令列表**：

| 命令 | 说明 |
| --- | --- |
| `command > file` | 将输出重定向到 file。 |
| `command < file` | 将输入重定向到 file。 |
| `command >> file` | 将输出以追加的方式重定向到 file。 |
| `n > file` | 将文件描述符为 n 的文件重定向到 file。 |
| `n >> file` | 将文件描述符为 n 的文件以追加的方式重定向到 file。 |
| `n >& m` | 将输出文件 m 和 n 合并。 |
| `n <& m` | 将输入文件 m 和 n 合并。 |
| `<< tag` | 将开始标记 tag 和结束标记 tag 之间的内容作为输入。 |

> 文件描述符
>
> - 0：标准输入（STDIN）
> - 1：标准输出（STDOUT）
> - 2：标准错误输出（STDERR）

## 重定向 `2>&1` 含义解释

`&` 表示重定向的目标不是一个文件，而是一个文件描述符。

**顺序问题示例**：

```sh
xxx > list 2>&1
```

先将要输出到 stdout 的内容重定向到文件 list，此时文件 list 就是这个程序的 stdout，再将 stderr 重定向到 stdout，也就是文件 list。

---

```sh
xxx 2>&1 > list
```

先将要输出到 stderr 的内容重定向到 stdout，此时会产生一个 stdout 的拷贝，作为程序的 stderr，而程序原本要输出到 stdout 的内容，依然是对接在 stdout 原身上的，因此第二步重定向 stdout，对 stdout 的拷贝不产生任何影响。
